# Northpoint Leadership Group — Portfolio Website Demo

A responsive multi-page coaching and leadership consultancy website created as a portfolio demonstration.

## Pages
Home, About, Services, Business Coaching, Executive Coaching, Health & Wellness Coaching, Mastermind Groups, Leadership Training, Case Studies, Events, Resources, Contact, Book a Session, Privacy Policy.

## Run locally
Open `index.html` in a browser. The site uses static HTML, CSS and JavaScript and can be hosted as a Render Static Site.

## Render settings
- Service type: Static Site
- Branch: main
- Root Directory: leave blank
- Build Command: leave blank
- Publish Directory: .

## Demo notes
Northpoint Leadership Group is a fictional brand. Case studies, events, and testimonials are illustrative. Contact/booking forms show a front-end confirmation only and do not transmit or store submissions. Replace demo contact details and review privacy/legal copy before any real commercial use.

## Images
Photography is loaded from fixed Unsplash image URLs, so an internet connection is required for those images to display.
